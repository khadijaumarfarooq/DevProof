# DevProof

AI-powered skill verifier. Paste your code, and DevProof scores it,
explains the score with evidence from the code, and shows skill bars,
badges and charts.

## Tech
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- AI: Google Gemini API

## Run locally
1. `cd BackEnd`
2. `python -m venv venv` then activate it
3. `python -m pip install -r requirements.txt`
4. Create a `.env` file with `GEMINI_API_KEY=your-key`
5. `python app.py`
6. Open `FrontEnd/index.html` in your browser
